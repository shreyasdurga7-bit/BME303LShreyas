# UT Austin BME Projects

A collection of computational modeling and simulation projects from my biomedical engineering coursework at UT Austin. Covers cardiovascular physiology, drug delivery, and tissue repair dynamics.

## Projects

**CardiovascularModel** — Windkessel model of arterial hemodynamics comparing baseline and caffeine conditions. Includes MATLAB scripts for measuring artery diameter, carotid compliance, and vascular resistance from ultrasound and Doppler imaging data.

**DiffusionModel** — Simulates controlled drug release from alginate beads using Fick's first law. Includes an implementation of the Ritger-Peppas equation for characterizing release kinetics.

**WoundHealingSimulation** — Interactive cellular automaton of wound healing dynamics built in Python. Models four tissue states evolving over simulated time using probabilistic Moore neighborhood rules.

## Languages

MATLAB, Python
